ESP32 API & Email Code

How the ESP32 talks to this website. The full Arduino code is smart_parking.ino in the project folder.

Endpoints (header x-api-key required)

POST /api/esp32/sync        every 3 s: {"bays":[0,1,0,0],"ip":"...","rssi":-60,"uptime":120}
                            reply: {"bays":["available","reserved",...],"commands":["open_entry"]}
POST /api/esp32/verify-pin  keypad: {"pin":"4821"}
                            reply: {"ok":true,"action":"entry|exit","gate":0|1,"bay":2}

If the ESP32 has not synced for 12 seconds the header turns to ESP32 Offline. While it keeps syncing the header shows ESP32 Online.

Email code

When a customer books, the server creates a 4-digit PIN, stores the booking in the database and emails the PIN. Set BREVO_API_KEY and MAIL_FROM in Render for real emails. Without them the email still shows in the Email Inbox tab.

POST https://api.brevo.com/v3/smtp/email
headers: api-key: <BREVO_API_KEY>
body:    { sender:{email:MAIL_FROM}, to:[{email}], subject, textContent }
